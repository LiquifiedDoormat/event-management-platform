# Event Management Platform

A web application for creating, managing, and attending events.

> Status: project setup. No application code yet. The tech stack hasn't been chosen.

## Repository

https://github.com/LiquifiedDoormat/event-management-platform

## Getting started

```bash
git clone https://github.com/LiquifiedDoormat/event-management-platform.git
cd event-management-platform
cp .env.example .env   # then fill in real values locally
```

## Environment variables

All configuration lives in `.env`, which is git-ignored. `.env.example` lists every variable with placeholder values only. Never commit real secrets.

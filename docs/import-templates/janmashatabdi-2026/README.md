# Janmashatabdi 2026 — full-scale sample import templates

Generated for local baseline performance testing (70 hotels, 150 hotel
coordinators, 16,000 attendees in 8 batches of 2,000, 150 buses — one bus per
coordinator). All phone numbers are synthetic but pass real Indian mobile
validation. Import in this order through /import:

1. `01-hotels.csv`
2. `02-hotel-coordinators.csv`
3. `03-attendees-batch-01.csv` through `03-attendees-batch-08.csv`
4. `04-buses.csv`

Demo data only — do not use against a production database.
